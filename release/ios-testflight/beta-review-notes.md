# TestFlight 베타 심사용 메모

## 테스트 계정

- 로그인 방식: 이메일
- 이메일: `[대표 입력 필요]`
- 비밀번호: `[대표 입력 필요]`

심사 제출 전 App Store Connect의 Beta App Review Information에 실제 테스트 계정을 입력해야 합니다. 자격 증명은 저장소에 커밋하지 않습니다.

## 핵심 검토 경로

1. 이메일 테스트 계정으로 로그인
2. 일정에서 회원 수업 선택 또는 일정 생성
3. 출석 처리
4. `수업 기록 → 말하기 → 완료`
5. AI 수업 요약 4칸 확인
6. 같은 회원의 다음 일정과 회원 상세에서 기억 카드 확인

## 마이크와 데이터 처리

- 마이크 권한은 수업 직후 짧은 음성 기록을 남길 때만 요청합니다.
- 녹음은 기록 정리를 위해 서버로 전송되고 전사 후 즉시 삭제되며 장기 보관하지 않습니다.
- 사용자가 권한을 영구 거부한 경우 `권한 설정`은 iOS의 해당 앱 설정 화면을 엽니다.
- 녹음 중 앱이 백그라운드로 전환되면 현재 녹음을 안전하게 중단·저장하고, 복귀 후 이어서 말할 수 있도록 안내합니다.

## 로그인 제공 방식

iOS 빌드에서는 Google 로그인 버튼을 노출하지 않습니다. iOS 사용자는 Apple로 로그인 또는 이메일 로그인/가입을 사용합니다. 이는 iOS에서 지원하지 않는 별도 Google 네이티브 로그인 경로를 심사 화면에 노출하지 않고, 실제 제공되는 로그인 방식만 명확히 보여주기 위한 제품 분기입니다.
