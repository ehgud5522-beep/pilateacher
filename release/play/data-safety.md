# Google Play 데이터 안전 답안 초안

기준 앱: `com.pilateacher.app` / 1.1.22 (37)

Google Play에서 **수집**은 앱 밖으로 전송하는 것을 뜻합니다. 기기 안에서만 처리하는 정보는 수집으로 보지 않지만, 요청 처리 직후 폐기하는 일시적 처리도 설문에는 포함해야 합니다. Firebase와 OpenAI는 앱 기능을 대신 처리하는 서비스 제공자로 운영한다는 전제에서 `공유 안 함`으로 작성했습니다.

## 공통 답변

| 질문 | 답변 | 근거 |
|---|---|---|
| 사용자 데이터를 수집하거나 공유하나요? | 예, 수집함 / 공유 안 함 | 로그인·클라우드 백업·AI 음성 처리·사용자 요청 진단 전송이 있음 |
| 전송 중 암호화하나요? | 예 | Firebase 및 OpenAI 요청은 HTTPS/TLS 사용 |
| 데이터 삭제를 요청할 수 있나요? | 예 | 앱의 `더보기 → 계정 → 계정 삭제`와 공개 삭제 안내 페이지 제공 |
| 계정 생성이 있나요? | 예 | 이메일·소셜 로그인 계정 사용 |

## 중요 확인

- 체형 사진은 기본적으로 기기에 저장되지만 현재 앱에는 사용자가 켤 수 있는 사진 클라우드 백업이 있습니다. 따라서 Play Console에서 사진을 `수집하지 않음`으로 답하면 실제 코드와 불일치합니다.
- Firebase/OpenAI를 `서비스 제공자` 예외로 공유에서 제외하려면 실제 계약·사용 목적이 서비스 제공 범위 안인지 대표가 최종 확인해야 합니다.
- 모든 활성 SDK가 HTTPS/TLS만 사용하는지 Play 제출 직전 네트워크 검사를 다시 수행해야 합니다.
